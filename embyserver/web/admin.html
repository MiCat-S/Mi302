增量和全量有什麼不同？

增量：讀 115 的生活事件（操作紀錄），處理上次同步之後的上傳、移動、改名、刪除；移動和改名時，本機的 strm 連同刮好的 nfo、海報一起搬。再依修改時間補抓沒有產生事件的上傳（例如離線下載）。速度快，適合常常跑。

全量：用 115 的「導出目錄樹」重新比對整個目錄，查漏補缺，預設每週自動跑一次。

任務第一次增量同步、或太久沒同步超出 115 保留的事件範圍時，會自動改跑全量。

同步選項

MoviePilot

Mi302 不自己刮削：同步產生新的 strm 後交給 MoviePilot 查影片資料，把 nfo 和海報寫到同一個資料夾，Mi302 再重新掃描。

連線

MoviePilot 帳號密碼（補全缺集需要；舊版刮削 API 也需要）

「補全缺集」建訂閱的 API 只接受帳號登入。舊版的刮削 API 不接受 API 令牌，測試連線出現「拒絕存取」時也要填。

刮削

把媒體庫裡還沒有 nfo 的影片、以及有 nfo 卻沒有劇照的集送去 MoviePilot。劇集沒有 tvshow.nfo 時整部劇一起刮削；已經刮削過的劇會帶上 tmdbid，MoviePilot 不必再搜尋。

補全缺集

先向 MoviePilot 查 TMDB 上每一季已經播出的集（沒有播出日期、又在媒體庫最後一集之後的不算），對照 Mi302 裡已有的集號；真的缺集的季才建訂閱，並請 MoviePilot 馬上搜尋。已播出的都有就不建訂閱。要先把 Mi302 加成 MoviePilot 的媒體伺服器（見下方），並填上面的 MoviePilot 帳號密碼。
