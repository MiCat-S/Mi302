增量和全量有什麼不同？

增量：讀 115 的生活事件（操作紀錄），處理上次同步之後的上傳、移動、改名、刪除；移動和改名時，本機的 strm 連同刮好的 nfo、海報一起搬。再依修改時間補抓沒有產生事件的上傳（例如離線下載）。速度快，適合常常跑。

全量：用 115 的「導出目錄樹」重新比對整個目錄，查漏補缺，預設每週自動跑一次。

任務第一次增量同步、或太久沒同步超出 115 保留的事件範圍時，會自動改跑全量。 說明

最近刪掉的

MoviePilot

Mi302 不自己刮削：同步產生新的 strm 後交給 MoviePilot 查影片資料，把 nfo 和海報寫到同一個資料夾，Mi302 再重新掃描。

連線

MoviePilot 帳號密碼（補全缺集、整理 115 網盤需要；舊版刮削 API 也需要）

「補全缺集」建訂閱的 API 只接受帳號登入。舊版的刮削 API 不接受 API 令牌，測試連線出現「拒絕存取」時也要填。

刮削

把媒體庫裡還沒有 nfo 的影片、以及有 nfo 卻沒有劇照的集送去 MoviePilot 刮削。 說明

補全缺集

對照 TMDB 上已經播出的集，真的缺集的季才向 MoviePilot 建訂閱並馬上搜尋。要先把 Mi302 加成 MoviePilot 的媒體伺服器（見「當成 Emby」），並在「連線」填 MoviePilot 帳號密碼。 說明

怎麼還原

1. 停止 Mi302。2. 把要還原的 .db 複製成資料夾裡的 library.db，並刪掉 library.db-wal、library.db-shm。3. 需要的話把同時間的 .yaml 換成 config.yaml。4. 啟動 Mi302。 說明

版本與更新

讀取中…

網頁上的更新和終端機的 mi302 update 一樣下載新版、需要時安裝相依套件；新版啟動不了會退回原本的版本。安裝腳本管的服務設定、ffprobe 還是要用 mi302 update 更新。 說明

刪除

勾選的檔案移到 115 回收站（在 115 可以還原），本機的 strm、nfo 和媒體庫裡的這幾集一起拿掉。預設只勾認不出集號的；集號是從檔名猜的通常是真的集，交給 MoviePilot 整理比刪掉好。
