装好 Mi302 之后，按本页在管理页面完成第一次设置：创建管理员、媒体库、115 同步、刮削和播放器。后半部分说明用户管理，以及配置文件 `config.yaml` 怎样工作。

管理页面只有繁体中文，下文引用按钮和字段名称时逐字转成简体，方便对照屏幕。不需要先改任何配置文件，全部在网页上完成。

## 1. 打开管理页面

用浏览器打开 `http://<主机>:8096/web`，端口是安装时选的。一键安装脚本最后打印的“管理网页”就是这个网址。

## 2. 创建管理员

第一次打开、还没有任何账号时，会看到“欢迎！先建立管理员帐号”：

1. “帐号”默认是 `admin`，可以改。
2. 填“密码”和“再输入一次密码”。
3. 点“建立并登入”。

这个账号可以登录管理页面，也可以在播放器里登录。之后的登录界面只接受管理员账号。

配置文件的 `users` 里已经写了账号时，Mi302 启动时会先创建它们，就不会出现这个界面，直接用那个账号登录。

## 3. 按“概览”的步骤操作

登录后是“概览”页。还没设置完时，上方有“开始设定”卡片，列出这几步：

| 步骤 | 什么时候打勾 |
| --- | --- |
| “建立媒体库” | 至少有一个媒体库 |
| “登入 115” | 115 已经登录 |
| “新增同步任务并同步” | 至少有一个同步任务完成过第一次同步 |
| “设定 MoviePilot 刮削（选用）” | 已经填好 MoviePilot 的连接信息 |

没完成的步骤旁边有“前往”按钮，会带你到对应的页面。前三步都完成后，这张卡片就不再出现。下面按同样的顺序说明。

## 4. 创建媒体库

媒体库是播放器首页看到的分类，例如“电影”“剧集”。在“媒体库”页：

1. 点“新增媒体库”。第一个媒体库默认叫“电影”。
2. 填名称，选类型“电影”或“剧集”。
3. 点“加入资料夹”。在“选择资料夹”窗口点选服务器上的文件夹，或在上方输入路径后点“前往”，再点“选这个资料夹”。一个媒体库可以有多个文件夹。
4. 点页面下方的“储存并扫描”。

文件夹是运行 Mi302 那台机器上的路径，运行 Mi302 的账号要能读取。下面有“国产剧”“日番”这类分类文件夹时，选上层文件夹就行，会自动往下找。文件夹结构和命名见[媒体库与扫描](媒体库与扫描)。

## 5. 登录 115 并同步

在“115 网盘”页：

1. 在“帐号”卡片点“扫码登入”，用手机 115 App 扫描并确认。扫码登录会占用一种 115 设备类型（默认是支付宝小程序），同类型的其他登录会被踢下线；要换类型，在“进阶设定”里改。
2. 在“同步任务”卡片：
   - “115 目录”旁点“浏览”，选 115 上的目录。
   - “放到本机资料夹”旁点“浏览”，选要放 strm 的本地文件夹。
   - 点“新增任务”。
3. 在“同步”卡片点“增量同步”。任务第一次同步时会自动改为全量同步。同步完只重新扫描有变动的文件夹。

本地文件夹要在某个媒体库的文件夹里，建议用子文件夹。例如媒体库“电影”的文件夹是 `/media/movies`，同步任务就放到 `/media/movies/115`。本地文件夹要填完整路径，两个任务的本地文件夹不能相同或互相包含。115 上的目录结构会原样保留。

最后设置自动同步。在“同步选项”卡片：

- “自动增量同步间隔（分钟）”默认是 0，也就是不自动同步。建议填 5。
- “自动全量同步间隔（小时）”默认是 168，也就是每周一次。

点“储存同步选项”。登录方式、增量和全量的区别、其他同步选项见[115 网盘与同步](115-网盘与同步)。

## 6. 刮削（可选）

Mi302 自己不刮削。没有 MoviePilot 时，115 上已经有的 nfo、海报、字幕会和 strm 一起下载下来（“同步选项”的“一并下载 115 上的 nfo、海报、字幕”，默认开启）。

有 MoviePilot 的话，在“MoviePilot”页：

1. 填“MoviePilot 网址”，例如 `http://192.168.1.10:3000`。
2. 填“API 令牌”，在 MoviePilot 的“设定 → 系统 → API 令牌”可以找到。
3. 点“储存”，再点“测试连线”。

之后同步生成的新 strm 会自动送去刮削。路径映射、补全缺集等见 [MoviePilot 集成](MoviePilot-集成)。

## 7. 在播放器里添加服务器

在 Infuse、VidHub、SenPlayer、Emby 官方 App 等播放器里添加 **Emby** 服务器：

- 地址：`http://<主机>:8096`，后面不加 `/web`。“概览”页的“在播放器里连线”卡片会显示这个地址，可以点复制。它显示的是你当前打开网页用的地址；如果你是用 `localhost` 打开的，要换成这台机器的局域网 IP。
- 账号：管理员账号，或在“使用者”页创建的账号。

播放器里显示的服务器名称，在“进阶设定”的“伺服器名称”里改，默认是 `Emby Server`。要在家以外的地方看，见[播放与外网访问](播放与外网访问)。

## 用户

“使用者”页列出所有账号、是“管理员”还是“一般使用者”，以及上次登录时间。

- 所有账号都可以在播放器里登录，各自有自己的观看记录和收藏。只有管理员能登录管理页面。
- 添加：在“新增使用者”填“帐号”和“密码”，要让对方也能管理时打开“管理员”，再点“新增”。密码不能为空。
- 每个账号旁边有“改密码”、“设为管理员”（或“取消管理员”）和删除按钮。删除账号会一起删除它的观看记录。
- 至少要保留一个管理员，最后一个管理员不能删除，也不能取消管理员。
- 播放器登录界面要不要列出账号名称，在“进阶设定”的“播放器登入画面列出使用者名称”设置，默认开启。

忘记密码时的重置方法见[日志与常见问题](日志与常见问题)。

## 配置文件 config.yaml

网页上的设置都保存在配置文件 `config.yaml`，两边保持一致。一键安装的在安装位置的 `config/config.yaml`（Linux 是 `/opt/mi302/config/config.yaml`）；手动运行的在执行命令时所在的文件夹。“进阶设定”页上方会显示完整路径。

- **自动生成**：第一次启动时自动生成，每一项都带说明注释，不用自己创建。
- **网页保存时写回**：在网页上保存设置时，Mi302 会重写整个文件，覆盖前把旧文件复制成 `config.yaml.bak`。文件每次都按模板重新生成，自己加的注释不会保留。
- **可以直接改文件**：改完在浏览器里刷新管理页面，Mi302 就会重新读取文件并应用。在网页上保存前，也会先读入手动改过的内容，不会把它覆盖掉。
- **格式写错时**：网页上方会出现“设定档有错，没有套用”的提示，Mi302 继续用上次读到的设置。改正后刷新网页即可。不过 Mi302 重启时如果配置文件格式错误，会无法启动，这时可以用 `config.yaml.bak` 还原。
- **不认识的项目**：打错字或旧版留下的项目会被忽略并发出警告，不影响启动。
- **要重启才生效**：`server` 的 `host`、`port`、`data_dir`。`users`、`p115.cookies`、`p115.timeout` 也只在启动时读取。

各项目的说明、默认值和范围见[配置文件参考](配置文件参考)。

### 不在配置文件里的数据

下面这些存在数据库 `data/library.db`，不写进配置文件：

- 账号和密码（只存密码哈希）
- 115 登录状态
- 在网页上创建的 API 密钥
- 观看记录、同步索引、媒体信息、学到的片头片尾等

配置文件里的 `users` 只用来预先创建账号：Mi302 启动时，列表里还不存在的账号会被创建；已经存在的账号不会被改动，之后在网页上改的密码也不会写回文件。这些密码以明文写在文件里，配置文件和它的备份要保管好。配置文件的 `api_keys` 是固定的 API 密钥，和网页上创建的密钥都能用。

旧版把网页设置和同步任务存在数据库里。更新后第一次启动时，Mi302 会自动把它们搬进配置文件。

数据库和配置文件的备份见[备份与还原](备份与还原)。
