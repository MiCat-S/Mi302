這一頁給想了解內部運作或參與開發的人：請求流程、路徑怎麼比對、已實作的 Emby 端點、管理 API、程式結構、怎麼跑測試，以及參考過的專案。

## 請求流程

Mi302 是一個 FastAPI 程式，用 uvicorn 執行，資料存在 SQLite（`data/library.db`）。

1. **掃描**：把媒體庫資料夾裡的 `.strm`、一般影片檔、nfo、圖片寫進資料庫，見 [媒體庫與掃描](媒體庫與掃描)。
2. **瀏覽**：播放器呼叫 Emby API（`/Users/{id}/Views`、`/Items`…），Mi302 從資料庫組出 Emby 的 `BaseItemDto`。
3. **播放資訊**：`POST /Items/{id}/PlaybackInfo`。strm 項目回 `Protocol=Http`、`IsRemote=true`，只允許直接播放（關閉轉碼），`DirectStreamUrl` 指回 `/videos/{id}/stream.{格式}`。
4. **串流**：播放器請求 `/Videos/{id}/stream`、`/Videos/{id}/original.xxx` 或 `/Items/{id}/Download`：
   - strm 項目：讀 strm 內容，套用路徑替換；帶 pickcode 就用播放器的 User-Agent 向 115 取直鏈，否則可以先跟完上游的重導向；最後回 `302 Location: <真實網址>`。
   - 一般影片檔：直接送檔，支援 Range。
5. **進度**：`/Sessions/Playing…` 記續播位置和已看，也拿來學片頭片尾，見 [片頭片尾跳過](片頭片尾跳過)。

細節見 [播放與外網連線](播放與外網連線)。Mi302 回報自己是 Emby Server 4.8.11.0。

## 路徑和參數

進來的每個 HTTP 請求先整理路徑，再比對路由：

- 路徑裡的英文字母轉小寫，其他字元不動（`/Persons/Émilie` 的 `É` 保留），所以路徑不分大小寫。
- 開頭的 `/emby`、`/mediabrowser` 拿掉，有沒有這個前綴都可以。
- 結尾的 `/` 拿掉。
- 查詢參數的名稱不分大小寫（`ParentId`、`parentid` 都可以）。

其他：

- 錯誤回應是純文字，和 Emby 一樣。
- CORS 全開。
- FastAPI 自動產生的 API 說明在 `/api-docs`。

## 認證

token 依序從這些地方找：

1. 標頭 `X-Emby-Token`、`X-MediaBrowser-Token`。
2. 標頭 `X-Emby-Authorization`（或 `Authorization`）裡的 `Token="…"`，格式是 `MediaBrowser Client="…", Device="…", DeviceId="…", Version="…", Token="…"`。
3. 查詢參數 `api_key`、`X-Emby-Token`、`ApiKey`、`X-MediaBrowser-Token`。

token 由 `POST /Users/AuthenticateByName` 發給。同一個使用者在同一個裝置（`DeviceId`）重新登入時，舊的 token 作廢。API 金鑰（設定檔的 `api_keys`，或在網頁上建立的）以管理員的身分執行（依名稱排序的第一個管理員），給 MoviePilot 這類程式用；它不能呼叫 `/web/api/…` 和 `/p115/…`。

## 已實作的 Emby 端點

路徑照 Emby 的寫法列出，實際上不分大小寫。「不用登入」以外的都要帶 token。

### 系統和使用者

| 端點 | 說明 |
| --- | --- |
| `GET /System/Info/Public` | 伺服器名稱、版本、id；不用登入 |
| `GET /System/Info` | 完整伺服器資訊 |
| `GET, POST /System/Ping` | 回 `Emby Server`；不用登入 |
| `GET /System/Endpoint` | 固定回「區域網路內」；不用登入 |
| `GET /Branding/Configuration` | 空的品牌設定；不用登入 |
| `GET /Users/Public` | 登入畫面的使用者清單（`server.public_users` 關掉時是空的）；不用登入 |
| `POST /Users/AuthenticateByName` | 登入，JSON 或表單，密碼欄位是 `Pw` 或 `Password`；不用登入 |
| `GET /Users` | 所有使用者；要管理員 |
| `GET /Users/{id}` | 使用者資料；只能查自己，管理員可以查別人 |
| `POST /Sessions/Logout` | 登出，作廢這個 token |
| `POST /Sessions/Capabilities`、`/Sessions/Capabilities/Full` | 接受但不處理 |
| `GET /Sessions` | 空清單 |
| `GET, POST /DisplayPreferences/{id}` | 固定的預設值，不儲存；不用登入 |
| `GET /Users/{id}/GroupingOptions`、`/Plugins`、`/Localization/{kind}` | 空清單；不用登入 |
| WebSocket `/embywebsocket` | 只回應 KeepAlive |

### 媒體庫和項目

| 端點 | 說明 |
| --- | --- |
| `GET /Users/{id}/Views`、`/Library/MediaFolders` | 媒體庫清單 |
| `GET /Library/VirtualFolders`、`/Library/VirtualFolders/Query`、`/Library/SelectableMediaFolders` | 媒體庫和資料夾路徑（MoviePilot 用） |
| `POST /Library/Refresh` | 全部重新掃描；要管理員 |
| `POST /Library/Media/Updated` | 只掃通知裡的路徑；要管理員 |
| `POST /Items/{id}/Refresh` | 只重掃這一項所在的劇或電影；要管理員 |
| `GET /Users/{id}/Items`、`/Items` | 查詢項目，見下面的參數 |
| `GET /Users/{id}/Items/{itemId}`、`/Items/{id}` | 單一項目的完整資料，含 `MediaSources`、`People`、`Chapters`；id 是人物 id 時回人物 |
| `GET /Users/{id}/Items/Latest` | 最近新增（`Limit`、`ParentId`、`IncludeItemTypes`；要集時以劇為單位） |
| `GET /Users/{id}/Items/Resume` | 繼續觀看 |
| `GET /Items/{id}/Ancestors` | 上層項目 |
| `GET /Items/Counts` | 電影、劇集、集的數量 |
| `GET /Shows/{id}/Seasons` | 季 |
| `GET /Shows/{id}/Episodes` | 集（`SeasonId`、`Season`、`StartIndex`、`Limit`、`Fields`） |
| `GET /Shows/NextUp` | 接著看（`SeriesId`、`Limit`） |
| `GET /Genres` | 所有類型 |
| `GET /Persons`、`/Persons/{name}` | 搜尋人物、依名稱找人物（原名、中文名都認） |
| `GET /Persons/{name}/Images/{type}` | 人物照片，302 到 nfo 裡的網址；不用登入 |
| `POST /Users/{id}/PlayedItems/{itemId}`；`DELETE`（或 `POST …/Delete`） | 標記已看、未看；對劇或季就是底下所有集 |
| `POST /Users/{id}/FavoriteItems/{itemId}`；`DELETE`（或 `POST …/Delete`） | 加入、移除收藏 |

`/Items` 的查詢參數：`ParentId`、`Recursive`、`IncludeItemTypes`（含 `Person` 時一併搜尋人物）、`ExcludeItemTypes`、`Ids`、`PersonIds`、`Person`、`IsFolder`、`SearchTerm`、`NameStartsWith`、`Years`、`Genres`、`Filters`（`IsPlayed`、`IsUnplayed`、`IsFavorite`、`IsResumable`）、`IsPlayed`、`IsFavorite`、`SortBy`、`SortOrder`、`StartIndex`、`Limit`、`Fields`（`MediaSources`、`People`、`Chapters`）、`UserId`。

`SortBy` 認得：`SortName`、`Name`、`DateCreated`、`DateLastContentAdded`、`PremiereDate`、`ProductionYear`、`CommunityRating`、`CriticRating`、`Runtime`、`Random`、`DatePlayed`、`PlayCount`、`IndexNumber`、`ParentIndexNumber`、`AiredEpisodeOrder`。

回空結果的端點（讓播放器不報錯）：`/Users/{id}/Items/{id}/Intros`、`/Items/{id}/Similar`、`/Movies/{id}/Similar`、`/Shows/{id}/Similar`、`/Videos/{id}/AdditionalParts`、`/Items/{id}/CriticReviews`、`/Users/{id}/Items/{id}/LocalTrailers`、`/Users/{id}/Items/{id}/SpecialFeatures`、`/Items/{id}/SpecialFeatures`、`/Items/{id}/ThemeMedia`。

### 圖片

| 端點 | 說明 |
| --- | --- |
| `GET /Items/{id}/Images/{type}[/{index}]` | 讀圖片，`type` 是 `Primary`、`Backdrop`、`Thumb`、`Logo`、`Art`；不用登入 |
| `POST /Items/{id}/Images/{type}[/{index}]` | 上傳圖片（base64 文字或圖片檔本身，最大 30 MB），存在 `data/images/`；要管理員 |
| `DELETE /Items/{id}/Images/{type}[/{index}]` | 刪掉上傳的圖片，改回資料夾裡的圖；要管理員 |
| `GET /Users/{id}/Images/{type}` | 使用者頭像，一律 404 |

### 播放

| 端點 | 說明 |
| --- | --- |
| `GET, POST /Items/{id}/PlaybackInfo` | 媒體來源 |
| `GET, HEAD /Videos/{id}/{name}` | 串流（`stream`、`stream.mkv`、`original.mkv`…）；`redirect.require_auth` 開著時要登入 |
| `GET, HEAD /Items/{id}/Download`、`/Items/{id}/File` | 下載；一律要登入，`server.allow_download` 關掉時回 403 |
| `POST /Sessions/Playing`、`/Sessions/Playing/Progress`、`/Sessions/Playing/Stopped` | 播放進度 |
| `POST /Sessions/Playing/Ping` | 接受但不處理 |
| `POST /Users/{id}/PlayingItems/{itemId}`、`…/Progress`；`DELETE`（或 `POST …/Delete`） | 舊版的播放進度回報 |

## 管理 API

管理網頁 `/web` 用的 API。除了 `/web/api/setup`，都要用管理員帳號登入後的 token（放在 `X-Emby-Token` 標頭），API 金鑰不行。請求和回應都是 JSON。

| 路徑 | 用途 |
| --- | --- |
| `GET, POST /web/api/setup` | 是否需要建立第一個管理員；建立它（只在還沒有任何帳號時可用） |
| `GET, PUT /web/api/settings` | 讀取、儲存網頁上的設定（寫進設定檔） |
| `GET, POST /web/api/scan` | 掃描進度和各媒體庫的項目數；開始掃描：`{"library": 名稱}`、`{"path": 路徑}`，都沒有就全部 |
| `GET, POST /web/api/users`；`PUT, DELETE /web/api/users/{id}` | 使用者 |
| `GET /web/api/browse`、`/web/api/115/browse` | 選伺服器上的資料夾、選 115 目錄 |
| `POST /web/api/moviepilot/test`、`GET /web/api/moviepilot/status`、`POST /web/api/moviepilot/scrape` | MoviePilot 測試連線、狀態、刮削缺少資料的項目 |
| `GET /web/api/series`、`POST /web/api/moviepilot/fill` | 劇集和集號空洞清單；補全缺集 |
| `GET /web/api/intro/status`、`POST /web/api/intro/clear` | 片頭片尾（`{"season_id": id}` 只清一季） |
| `GET /web/api/people/status`、`POST /web/api/people/resolve` | 演職人員中文名 |
| `GET, POST /web/api/backups`；`GET /web/api/backups/{name}` | 備份清單、立即備份、下載備份 |
| `GET /web/api/mediainfo/status`、`POST /web/api/mediainfo/probe` | 媒體資訊 |
| `GET /web/api/logs`、`/web/api/logs/download` | 日誌、下載日誌檔 |
| `GET, POST /web/api/apikeys`；`DELETE /web/api/apikeys/{key}` | API 金鑰 |
| `GET /p115/status` | 115 帳號狀態 |
| `POST /p115/qrcode`、`GET /p115/qrcode/status`、`POST /p115/cookies`、`POST /p115/logout` | 掃碼登入、貼 cookie、登出 |
| `POST /p115/open/qrcode`、`GET /p115/open/qrcode/status`、`POST /p115/open/logout` | 115 開放平台授權 |
| `POST /p115/strm/sync?mode=incremental`（不帶就是全量）、`GET /p115/strm/status`、`PUT /p115/strm/tasks` | 同步、同步狀態、同步任務 |

`GET /web` 是管理網頁本身，`/web/115` 轉到 `/web#115`。

## 程式結構

`embyserver/` 底下每個模組：

| 模組 | 內容 |
| --- | --- |
| `__main__.py` | 命令列入口：`python -m embyserver [-c config.yaml] [--scan] [--sync-115 [incremental]] [--reset-password 帳號 新密碼]` |
| `app.py` | 組裝 FastAPI 程式、整理路徑、啟動背景工作 |
| `auth.py` | 使用者、token、Emby 認證標頭 |
| `backup.py` | 每天備份資料庫和設定檔 |
| `config.py` | 設定檔的資料結構和讀取 |
| `config_file.py` | 把設定寫回 `config.yaml` |
| `settings.py` | 網頁上可改的設定：驗證、套用、和設定檔同步 |
| `db.py` | SQLite 資料表和存取 |
| `dto.py` | 資料庫列轉成 Emby 的 `BaseItemDto`、`UserDto`、`MediaSourceInfo` |
| `filetypes.py` | 共用的副檔名清單 |
| `http_util.py` | 呼叫外部服務的 httpx Client，把連線錯誤轉成看得懂的原因 |
| `intro.py` | 從播放行為學片頭片尾 |
| `logs.py` | 日誌：終端、日誌檔、記憶體，遮掉憑證 |
| `mediainfo.py` | 媒體資訊：ffprobe 結果和 `X-mediainfo.json` 轉成 Emby 格式 |
| `prober.py` | 用 ffprobe 探測 strm 指向的影片 |
| `moviepilot.py` | 刮削、補全缺集交給 MoviePilot |
| `p115.py` | 115：掃碼登入、取直鏈、列目錄、生活事件、熔斷 |
| `p115_open.py` | 115 開放平台通道 |
| `people.py` | 演職人員、中文名、類型中文化 |
| `redirect.py` | 解析 strm 真實網址、路徑替換、重導向快取 |
| `scanner.py` | 媒體庫掃描 |
| `strm_sync.py` | 從 115 產生 strm、下載中繼資料 |
| `textutil.py` | 拼音排序、拼音搜尋、繁簡轉換 |
| `routes/system.py` | System、Users、Sessions 等端點 |
| `routes/items.py` | 媒體庫、項目查詢、使用者資料、圖片 |
| `routes/playback.py` | PlaybackInfo、串流、進度回報、片頭片尾端點 |
| `routes/p115.py` | 115 登入和同步的管理 API、pickcode 短連結 |
| `routes/web.py` | 管理網頁和它的 API |
| `routes/common.py` | 路由共用的小工具 |
| `web/admin.html` | 管理網頁（單一檔案，HTML、CSS、JavaScript 都在裡面） |

資料庫 `library.db` 的資料表：`meta`（伺服器 id、115 登入狀態、同步進度等）、`users`、`tokens`、`items`、`user_data`（觀看紀錄、收藏）、`p115_index`（115 檔案 id 對本機路徑）、`media_info`、`people`、`person_names`、`intro_obs`、`mp_no_image`。

## 開發和測試

需要 Python 3.10 以上。在 venv 裡：

```bash
pip install -r requirements.txt pytest
python -m pytest
```

改了 `install.sh` 之後：

```bash
shellcheck install.sh
```

改了 `embyserver/web/admin.html` 之後，把 `<script>` 抽出來檢查 JavaScript 語法：

```bash
python3 -c "import re; print(re.search(r'<script>(.*)</script>', open('embyserver/web/admin.html', encoding='utf-8').read(), re.S).group(1))" > /tmp/admin.js
node --check /tmp/admin.js
```

- [xiao-vvv/emby-mediainfo](https://github.com/xiao-vvv/emby-mediainfo)（MIT 授權）：ffprobe 到 Emby 欄位的對照、探測的限速和 115 熔斷規則改寫自這個專案，版權聲明保留在 [`embyserver/mediainfo.py`](https://github.com/MiCat-S/Mi302/blob/main/embyserver/mediainfo.py)。
