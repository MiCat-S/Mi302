裝好 Mi302 之後，照這頁在管理網頁完成第一次設定：建立管理員、媒體庫、115 同步、刮削和播放器。後半段說明使用者管理，以及設定檔 `config.yaml` 怎麼運作。

不需要先改任何設定檔，全部在網頁上完成。

## 1. 打開管理網頁

用瀏覽器開 `http://<主機>:8096/web`，埠號是安裝時選的。一鍵安裝腳本最後印出的「管理網頁」就是這個網址。

## 2. 建立管理員

第一次打開、還沒有任何帳號時，會看到「歡迎！先建立管理員帳號」：

1. 「帳號」預設是 `admin`，可以改。
2. 填「密碼」和「再輸入一次密碼」。
3. 按「建立並登入」。

這組帳號可以登入管理網頁，也可以在播放器裡登入。之後的登入畫面只接受管理員帳號。

設定檔的 `users` 裡已經寫了帳號時，Mi302 啟動時會先建立它們，就不會出現這個畫面，直接用那組帳號登入。

## 3. 照「概覽」的步驟做

登入後是「概覽」頁。還沒設定完時，上方有「開始設定」卡片，列出這幾步：

| 步驟 | 什麼時候打勾 |
| --- | --- |
| 建立媒體庫 | 至少有一個媒體庫 |
| 登入 115 | 115 已經登入 |
| 新增同步任務並同步 | 至少有一個同步任務完成過第一次同步 |
| 設定 MoviePilot 刮削（選用） | 已經填好 MoviePilot 的連線資料 |

沒完成的步驟旁邊有「前往」按鈕，會帶你到對應的頁面。前三步都完成後，這張卡片就不再出現。下面照同樣的順序說明。

## 4. 建立媒體庫

媒體庫是播放器首頁看到的分類，例如「電影」「劇集」。在「媒體庫」頁：

1. 按「新增媒體庫」。第一個媒體庫預設叫「電影」。
2. 填名稱，選類型「電影」或「劇集」。
3. 按「加入資料夾」。在「選擇資料夾」視窗點選伺服器上的資料夾，或在上方輸入路徑後按「前往」，再按「選這個資料夾」。一個媒體庫可以有多個資料夾。
4. 按頁面下方的「儲存並掃描」。

資料夾是執行 Mi302 那台機器上的路徑，執行 Mi302 的帳號要讀得到。底下有「国产剧」「日番」這類分類資料夾時，選上層資料夾就好，會自動往下找。資料夾結構和命名見[媒體庫與掃描](媒體庫與掃描)。

## 5. 登入 115 並同步

在「115 網盤」頁：

1. 在「帳號」卡片按「掃碼登入」，用手機 115 App 掃描並確認。掃碼登入會佔用一種 115 裝置類型（預設是支付寶小程式），同類型的其他登入會被踢下線；要換類型，在「進階設定」改。
2. 在「同步任務」卡片：
   - 「115 目錄」旁按「瀏覽」，選 115 上的目錄。
   - 「放到本機資料夾」旁按「瀏覽」，選要放 strm 的本機資料夾。
   - 按「新增任務」。
3. 在「同步」卡片按「增量同步」。任務第一次同步時會自動改跑全量同步。同步完只重新掃描有變動的資料夾。

本機資料夾要在某個媒體庫的資料夾裡，建議用子資料夾。例如媒體庫「電影」的資料夾是 `/media/movies`，同步任務就放到 `/media/movies/115`。本機資料夾要填完整路徑，兩個任務的本機資料夾不能相同或互相包含。115 上的目錄結構會原樣保留。

最後設定自動同步。在「同步選項」卡片：

- 「自動增量同步間隔（分鐘）」預設是 0，也就是不自動同步。建議填 5。
- 「自動全量同步間隔（小時）」預設是 168，也就是每週一次。

按「儲存同步選項」。登入方式、增量和全量的差別、其他同步選項見[115 網盤與同步](115-網盤與同步)。

## 6. 刮削（選用）

Mi302 自己不刮削。沒有 MoviePilot 時，115 上已經有的 nfo、海報、字幕會和 strm 一起下載下來（「同步選項」的「一併下載 115 上的 nfo、海報、字幕」，預設開啟）。

有 MoviePilot 的話，在「MoviePilot」頁：

1. 填「MoviePilot 網址」，例如 `http://192.168.1.10:3000`。
2. 填「API 令牌」，在 MoviePilot 的「設定 → 系統 → API 令牌」可以找到。
3. 按「儲存」，再按「測試連線」。

之後同步產生的新 strm 會自動送去刮削。路徑對應、補全缺集等見 [MoviePilot 整合](MoviePilot-整合)。

## 7. 在播放器裡新增伺服器

在 Infuse、VidHub、SenPlayer、Emby 官方 App 等播放器裡新增 **Emby** 伺服器：

- 位址：`http://<主機>:8096`，後面不加 `/web`。「概覽」頁的「在播放器裡連線」卡片會顯示這個位址，可以按複製。它顯示的是你目前開網頁用的位址；如果你是用 `localhost` 開的，要換成這台機器的區網 IP。
- 帳號：管理員帳號，或在「使用者」頁建立的帳號。

播放器裡顯示的伺服器名稱，在「進階設定」的「伺服器名稱」改，預設是 `Emby Server`。要在家以外的地方看，見[播放與外網連線](播放與外網連線)。

## 使用者

「使用者」頁列出所有帳號、是「管理員」還是「一般使用者」，以及上次登入時間。

- 所有帳號都可以在播放器裡登入，各自有自己的觀看紀錄和收藏。只有管理員能登入管理網頁。
- 新增：在「新增使用者」填「帳號」和「密碼」，要讓對方也能管理時打開「管理員」，再按「新增」。密碼不能空白。
- 每個帳號旁邊有「改密碼」、「設為管理員」（或「取消管理員」）和刪除按鈕。刪除帳號會一起刪除它的觀看紀錄。
- 至少要保留一個管理員，最後一個管理員不能刪除，也不能取消管理員。
- 播放器登入畫面要不要列出帳號名稱，在「進階設定」的「播放器登入畫面列出使用者名稱」設定，預設開啟。

忘記密碼時的重設方法見[日誌與常見問題](日誌與常見問題)。

## 設定檔 config.yaml

網頁上的設定都存在設定檔 `config.yaml`，兩邊保持一致。一鍵安裝的在安裝位置的 `config/config.yaml`（Linux 是 `/opt/mi302/config/config.yaml`）；手動執行的在執行指令時所在的資料夾。「進階設定」頁上方會顯示完整路徑。

- **自動產生**：第一次啟動時自動產生，每一項都附說明註解，不用自己建立。
- **網頁儲存時寫回**：在網頁上儲存設定時，Mi302 會重寫整個檔案，覆寫前把舊檔複製成 `config.yaml.bak`。檔案每次都依範本重新產生，自己加的註解不會保留。
- **可以直接改檔案**：改完在瀏覽器重新整理管理網頁，Mi302 就會重新讀檔並套用。在網頁上儲存前，也會先讀進手動改過的內容，不會把它蓋掉。
- **格式寫錯時**：網頁上方會出現「設定檔有錯，沒有套用」的提示，Mi302 繼續用上次讀到的設定。修正後重新整理網頁即可。不過 Mi302 重新啟動時如果設定檔格式錯誤，會無法啟動，這時可以用 `config.yaml.bak` 還原。
- **不認得的項目**：打錯字或舊版留下的項目會被略過並發出警告，不影響啟動。
- **要重新啟動才生效**：`server` 的 `host`、`port`、`data_dir`。`users`、`p115.cookies`、`p115.timeout` 也只在啟動時讀取。

各項目的說明、預設值和範圍見[設定檔參考](設定檔參考)。

### 不在設定檔裡的資料

下面這些存在資料庫 `data/library.db`，不寫進設定檔：

- 帳號和密碼（只存密碼雜湊）
- 115 登入狀態
- 在網頁上建立的 API 金鑰
- 觀看紀錄、同步索引、媒體資訊、學到的片頭片尾等

設定檔裡的 `users` 只用來預先建立帳號：Mi302 啟動時，清單裡還不存在的帳號會被建立；已經存在的帳號不會被改動，之後在網頁上改的密碼也不會寫回檔案。這些密碼以明碼寫在檔案裡，設定檔和它的備份要收好。設定檔的 `api_keys` 是固定的 API 金鑰，和網頁上建立的金鑰都能用。

舊版把網頁設定和同步任務存在資料庫裡。更新後第一次啟動時，Mi302 會自動把它們搬進設定檔。

資料庫和設定檔的備份見[備份與還原](備份與還原)。
