这一页写给想了解内部运作或参与开发的人：请求流程、路径怎么匹配、已实现的 Emby 接口、管理 API、代码结构、怎么运行测试，以及参考过的项目。

## 请求流程

Mi302 是一个 FastAPI 程序，用 uvicorn 运行，数据存在 SQLite（`data/library.db`）。

1. **扫描**：把媒体库文件夹里的 `.strm`、普通视频文件、nfo、图片写进数据库，见 [媒体库与扫描](媒体库与扫描)。
2. **浏览**：播放器调用 Emby API（`/Users/{id}/Views`、`/Items`…），Mi302 从数据库组装出 Emby 的 `BaseItemDto`。
3. **播放信息**：`POST /Items/{id}/PlaybackInfo`。strm 项目返回 `Protocol=Http`、`IsRemote=true`，只允许直接播放（关闭转码），`DirectStreamUrl` 指回 `/videos/{id}/stream.{格式}`。
4. **串流**：播放器请求 `/Videos/{id}/stream`、`/Videos/{id}/original.xxx` 或 `/Items/{id}/Download`：
   - strm 项目：读取 strm 内容，应用路径替换；带 pickcode 就用播放器的 User-Agent 向 115 获取直链，否则可以先跟随上游的重定向；最后返回 `302 Location: <真实地址>`。
   - 普通视频文件：直接发送文件，支持 Range。
5. **进度**：`/Sessions/Playing…` 记录续播位置和已看，也用来学习片头片尾，见 [片头片尾跳过](片头片尾跳过)。

细节见 [播放与外网访问](播放与外网访问)。Mi302 对外报告自己是 Emby Server 4.8.11.0。

## 路径和参数

每个进来的 HTTP 请求先整理路径，再匹配路由：

- 路径里的英文字母转成小写，其他字符不动（`/Persons/Émilie` 的 `É` 保留），所以路径不区分大小写。
- 去掉开头的 `/emby`、`/mediabrowser`，有没有这个前缀都可以。
- 去掉结尾的 `/`。
- 查询参数的名称不区分大小写（`ParentId`、`parentid` 都可以）。

其他：

- 错误响应是纯文本，和 Emby 一样。
- CORS 全开。
- FastAPI 自动生成的 API 文档在 `/api-docs`。

## 认证

token 依次从这些地方查找：

1. 请求头 `X-Emby-Token`、`X-MediaBrowser-Token`。
2. 请求头 `X-Emby-Authorization`（或 `Authorization`）里的 `Token="…"`，格式是 `MediaBrowser Client="…", Device="…", DeviceId="…", Version="…", Token="…"`。
3. 查询参数 `api_key`、`X-Emby-Token`、`ApiKey`、`X-MediaBrowser-Token`。

token 由 `POST /Users/AuthenticateByName` 签发。同一个用户在同一台设备（`DeviceId`）重新登录时，旧的 token 作废。API 密钥（配置文件的 `api_keys`，或在网页上创建的）以管理员的身份运行（按名称排序的第一个管理员），给 MoviePilot 这类程序用；它不能调用 `/web/api/…` 和 `/p115/…`。

## 已实现的 Emby 接口

路径按 Emby 的写法列出，实际上不区分大小写。除了标注“不用登录”的，都要带 token。

### 系统和用户

| 接口 | 说明 |
| --- | --- |
| `GET /System/Info/Public` | 服务器名称、版本、id；不用登录 |
| `GET /System/Info` | 完整服务器信息 |
| `GET, POST /System/Ping` | 返回 `Emby Server`；不用登录 |
| `GET /System/Endpoint` | 固定返回“在局域网内”；不用登录 |
| `GET /Branding/Configuration` | 空的品牌设置；不用登录 |
| `GET /Users/Public` | 登录界面的用户列表（`server.public_users` 关掉时为空）；不用登录 |
| `POST /Users/AuthenticateByName` | 登录，JSON 或表单，密码字段是 `Pw` 或 `Password`；不用登录 |
| `GET /Users` | 所有用户；需要管理员 |
| `GET /Users/{id}` | 用户数据；只能查自己，管理员可以查别人 |
| `POST /Sessions/Logout` | 退出登录，作废这个 token |
| `POST /Sessions/Capabilities`、`/Sessions/Capabilities/Full` | 接受但不处理 |
| `GET /Sessions` | 空列表 |
| `GET, POST /DisplayPreferences/{id}` | 固定的默认值，不保存；不用登录 |
| `GET /Users/{id}/GroupingOptions`、`/Plugins`、`/Localization/{kind}` | 空列表；不用登录 |
| WebSocket `/embywebsocket` | 只响应 KeepAlive |

### 媒体库和项目

| 接口 | 说明 |
| --- | --- |
| `GET /Users/{id}/Views`、`/Library/MediaFolders` | 媒体库列表 |
| `GET /Library/VirtualFolders`、`/Library/VirtualFolders/Query`、`/Library/SelectableMediaFolders` | 媒体库和文件夹路径（MoviePilot 用） |
| `POST /Library/Refresh` | 全部重新扫描；需要管理员 |
| `POST /Library/Media/Updated` | 只扫描通知里的路径；需要管理员 |
| `POST /Items/{id}/Refresh` | 只重扫这一项所在的剧或电影；需要管理员 |
| `GET /Users/{id}/Items`、`/Items` | 查询项目，参数见下文 |
| `GET /Users/{id}/Items/{itemId}`、`/Items/{id}` | 单个项目的完整数据，含 `MediaSources`、`People`、`Chapters`；id 是人物 id 时返回人物 |
| `GET /Users/{id}/Items/Latest` | 最近添加（`Limit`、`ParentId`、`IncludeItemTypes`；请求集时以剧为单位） |
| `GET /Users/{id}/Items/Resume` | 继续观看 |
| `GET /Items/{id}/Ancestors` | 上级项目 |
| `GET /Items/Counts` | 电影、剧集、集的数量 |
| `GET /Shows/{id}/Seasons` | 季 |
| `GET /Shows/{id}/Episodes` | 集（`SeasonId`、`Season`、`StartIndex`、`Limit`、`Fields`） |
| `GET /Shows/NextUp` | 接着看（`SeriesId`、`Limit`） |
| `GET /Genres` | 所有类型 |
| `GET /Persons`、`/Persons/{name}` | 搜索人物、按名称查找人物（原名、中文名都识别） |
| `GET /Persons/{name}/Images/{type}` | 人物照片，302 到 nfo 里的地址；不用登录 |
| `POST /Users/{id}/PlayedItems/{itemId}`；`DELETE`（或 `POST …/Delete`） | 标记已看、未看；对剧或季就是下面所有集 |
| `POST /Users/{id}/FavoriteItems/{itemId}`；`DELETE`（或 `POST …/Delete`） | 加入、移除收藏 |

`/Items` 的查询参数：`ParentId`、`Recursive`、`IncludeItemTypes`（含 `Person` 时同时搜索人物）、`ExcludeItemTypes`、`Ids`、`PersonIds`、`Person`、`IsFolder`、`SearchTerm`、`NameStartsWith`、`Years`、`Genres`、`Filters`（`IsPlayed`、`IsUnplayed`、`IsFavorite`、`IsResumable`）、`IsPlayed`、`IsFavorite`、`SortBy`、`SortOrder`、`StartIndex`、`Limit`、`Fields`（`MediaSources`、`People`、`Chapters`）、`UserId`。

`SortBy` 支持：`SortName`、`Name`、`DateCreated`、`DateLastContentAdded`、`PremiereDate`、`ProductionYear`、`CommunityRating`、`CriticRating`、`Runtime`、`Random`、`DatePlayed`、`PlayCount`、`IndexNumber`、`ParentIndexNumber`、`AiredEpisodeOrder`。

返回空结果的接口（让播放器不报错）：`/Users/{id}/Items/{id}/Intros`、`/Items/{id}/Similar`、`/Movies/{id}/Similar`、`/Shows/{id}/Similar`、`/Videos/{id}/AdditionalParts`、`/Items/{id}/CriticReviews`、`/Users/{id}/Items/{id}/LocalTrailers`、`/Users/{id}/Items/{id}/SpecialFeatures`、`/Items/{id}/SpecialFeatures`、`/Items/{id}/ThemeMedia`。

### 图片

| 接口 | 说明 |
| --- | --- |
| `GET /Items/{id}/Images/{type}[/{index}]` | 读取图片，`type` 是 `Primary`、`Backdrop`、`Thumb`、`Logo`、`Art`；不用登录 |
| `POST /Items/{id}/Images/{type}[/{index}]` | 上传图片（base64 文本或图片文件本身，最大 30 MB），保存在 `data/images/`；需要管理员 |
| `DELETE /Items/{id}/Images/{type}[/{index}]` | 删除上传的图片，改回文件夹里的图；需要管理员 |
| `GET /Users/{id}/Images/{type}` | 用户头像，一律 404 |

### 播放

| 接口 | 说明 |
| --- | --- |
| `GET, POST /Items/{id}/PlaybackInfo` | 媒体源 |
| `GET, HEAD /Videos/{id}/{name}` | 串流（`stream`、`stream.mkv`、`original.mkv`…）；`redirect.require_auth` 开着时需要登录 |
| `GET, HEAD /Items/{id}/Download`、`/Items/{id}/File` | 下载；一律需要登录，`server.allow_download` 关掉时返回 403 |
| `POST /Sessions/Playing`、`/Sessions/Playing/Progress`、`/Sessions/Playing/Stopped` | 播放进度 |
| `POST /Sessions/Playing/Ping` | 接受但不处理 |
| `POST /Users/{id}/PlayingItems/{itemId}`、`…/Progress`；`DELETE`（或 `POST …/Delete`） | 旧版的播放进度上报 |

## 管理 API

管理页面 `/web` 用的 API。除了 `/web/api/setup`，都要用管理员账号登录后的 token（放在 `X-Emby-Token` 请求头），API 密钥不行。请求和响应都是 JSON。

| 路径 | 用途 |
| --- | --- |
| `GET, POST /web/api/setup` | 是否需要创建第一个管理员；创建它（只在还没有任何账号时可用） |
| `GET, PUT /web/api/settings` | 读取、保存网页上的设置（写进配置文件） |
| `GET, POST /web/api/scan` | 扫描进度和各媒体库的项目数；开始扫描：`{"library": 名称}`、`{"path": 路径}`，都没有就扫描全部 |
| `GET, POST /web/api/users`；`PUT, DELETE /web/api/users/{id}` | 用户 |
| `GET /web/api/browse`、`/web/api/115/browse` | 选择服务器上的文件夹、选择 115 目录 |
| `POST /web/api/moviepilot/test`、`GET /web/api/moviepilot/status`、`POST /web/api/moviepilot/scrape` | MoviePilot 测试连接、状态、刮削缺少数据的项目 |
| `GET /web/api/series`、`POST /web/api/moviepilot/fill` | 剧集和集号空缺列表；补全缺集 |
| `GET /web/api/intro/status`、`POST /web/api/intro/clear` | 片头片尾（`{"season_id": id}` 只清除一季） |
| `GET /web/api/people/status`、`POST /web/api/people/resolve` | 演职人员中文名 |
| `GET, POST /web/api/backups`；`GET /web/api/backups/{name}` | 备份列表、立即备份、下载备份 |
| `GET /web/api/mediainfo/status`、`POST /web/api/mediainfo/probe` | 媒体信息 |
| `GET /web/api/logs`、`/web/api/logs/download` | 日志、下载日志文件 |
| `GET, POST /web/api/apikeys`；`DELETE /web/api/apikeys/{key}` | API 密钥 |
| `GET /p115/status` | 115 账号状态 |
| `POST /p115/qrcode`、`GET /p115/qrcode/status`、`POST /p115/cookies`、`POST /p115/logout` | 扫码登录、粘贴 cookie、退出登录 |
| `POST /p115/open/qrcode`、`GET /p115/open/qrcode/status`、`POST /p115/open/logout` | 115 开放平台授权 |
| `POST /p115/strm/sync?mode=incremental`（不带就是全量）、`GET /p115/strm/status`、`PUT /p115/strm/tasks` | 同步、同步状态、同步任务 |

`GET /web` 是管理页面本身，`/web/115` 跳转到 `/web#115`。

## 代码结构

`embyserver/` 下的每个模块：

| 模块 | 内容 |
| --- | --- |
| `__main__.py` | 命令行入口：`python -m embyserver [-c config.yaml] [--scan] [--sync-115 [incremental]] [--reset-password 账号 新密码]` |
| `app.py` | 组装 FastAPI 程序、整理路径、启动后台任务 |
| `auth.py` | 用户、token、Emby 认证请求头 |
| `backup.py` | 每天备份数据库和配置文件 |
| `config.py` | 配置文件的数据结构和读取 |
| `config_file.py` | 把设置写回 `config.yaml` |
| `settings.py` | 网页上可改的设置：校验、应用、和配置文件同步 |
| `db.py` | SQLite 数据表和访问 |
| `dto.py` | 数据库行转成 Emby 的 `BaseItemDto`、`UserDto`、`MediaSourceInfo` |
| `filetypes.py` | 共用的扩展名列表 |
| `http_util.py` | 调用外部服务的 httpx Client，把连接错误转成看得懂的原因 |
| `intro.py` | 从播放行为学习片头片尾 |
| `logs.py` | 日志：终端、日志文件、内存，遮盖凭证 |
| `mediainfo.py` | 媒体信息：ffprobe 结果和 `X-mediainfo.json` 转成 Emby 格式 |
| `prober.py` | 用 ffprobe 探测 strm 指向的视频 |
| `moviepilot.py` | 刮削、补全缺集交给 MoviePilot |
| `p115.py` | 115：扫码登录、获取直链、列目录、生活事件、熔断 |
| `p115_open.py` | 115 开放平台通道 |
| `people.py` | 演职人员、中文名、类型中文化 |
| `redirect.py` | 解析 strm 真实地址、路径替换、重定向缓存 |
| `scanner.py` | 媒体库扫描 |
| `strm_sync.py` | 从 115 生成 strm、下载元数据 |
| `textutil.py` | 拼音排序、拼音搜索、繁简转换 |
| `routes/system.py` | System、Users、Sessions 等接口 |
| `routes/items.py` | 媒体库、项目查询、用户数据、图片 |
| `routes/playback.py` | PlaybackInfo、串流、进度上报、片头片尾接口 |
| `routes/p115.py` | 115 登录和同步的管理 API、pickcode 短链接 |
| `routes/web.py` | 管理页面和它的 API |
| `routes/common.py` | 路由共用的小工具 |
| `web/admin.html` | 管理页面（单个文件，HTML、CSS、JavaScript 都在里面） |

数据库 `library.db` 的数据表：`meta`（服务器 id、115 登录状态、同步进度等）、`users`、`tokens`、`items`、`user_data`（观看记录、收藏）、`p115_index`（115 文件 id 对应本地路径）、`media_info`、`people`、`person_names`、`intro_obs`、`mp_no_image`。

## 开发和测试

需要 Python 3.10 以上。在 venv 里：

```bash
pip install -r requirements.txt pytest
python -m pytest
```

改了 `install.sh` 之后：

```bash
shellcheck install.sh
```

改了 `embyserver/web/admin.html` 之后，把 `<script>` 抽出来检查 JavaScript 语法：

```bash
python3 -c "import re; print(re.search(r'<script>(.*)</script>', open('embyserver/web/admin.html', encoding='utf-8').read(), re.S).group(1))" > /tmp/admin.js
node --check /tmp/admin.js
```
