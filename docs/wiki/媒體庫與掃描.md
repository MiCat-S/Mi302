這一頁說明媒體庫的資料夾怎麼放、Mi302 怎麼掃描，以及中文片名的排序搜尋、演職人員中文名、類型中文化和媒體庫封面。

## 媒體庫和資料夾

媒體庫在管理網頁的「媒體庫」分頁建立：按「新增媒體庫」，取名，類型選「電影」或「劇集」，按「加入資料夾」選伺服器上的資料夾，最後按「儲存並掃描」。一個媒體庫可以有好幾個資料夾。

Mi302 不自己刮削，只讀資料夾裡已經有的檔案：

- 影片：`.strm` 和一般影片檔（`.mkv` `.mp4` `.m4v` `.avi` `.ts` `.m2ts` `.mov` `.wmv` `.flv` `.webm` `.rmvb` `.mpg` `.mpeg` `.iso` `.3gp`）。
- 中繼資料：nfo 和圖片（`.jpg` `.jpeg` `.png` `.webp`）。這些可以從 115 同步時一起下載，或交給 MoviePilot 刮削，見 [MoviePilot 整合](MoviePilot-整合)。

典型的結構：

```
movies/
  Inception (2010)/
    Inception (2010).strm
    Inception (2010).nfo        # 或 movie.nfo
    poster.jpg  fanart.jpg
tv/
  Dark (2017)/
    tvshow.nfo  poster.jpg  fanart.jpg
    Season 1/
      Dark.S01E01.strm
      Dark.S01E01.nfo
      Dark.S01E01-thumb.jpg
```

找電影和劇集資料夾時，名稱以 `.`、`@`、`#` 開頭的資料夾會略過（例如 NAS 的 `@eaDir`、`#recycle`）。

### 電影

- 每個影片檔是一部電影。
- 資料夾裡只有這一部影片（而且不是直接放在媒體庫資料夾底下）時，資料夾名稱帶年份、或檔名沒有年份，就用資料夾名稱當片名，例如 `Inception (2010)`。這種資料夾也讀 `movie.nfo`。
- 其他情況用檔名：認得 `片名 (年份)`，或去掉 `1080p`、`BluRay`、`x265` 這類字樣後取片名和年份。
- nfo 裡有 `<title>` 時以 nfo 為準。

### 劇集

每個劇集資料夾是一部劇。劇集資料夾裡任何一層的影片都算這部劇的集，可以放在季資料夾裡，也可以直接放在劇集資料夾裡。

## 季和集的命名

季資料夾的名稱：

| 寫法 | 例子 | 季 |
| --- | --- | --- |
| `Season N`、`Series N`（中間可以有空格、點、底線、減號） | `Season 1`、`Season.02`、`Series 3` | N |
| `SN` | `S01`、`s2` | N |
| `第N季`、`第N部`（阿拉伯數字或中文數字） | `第1季`、`第一季`、`第十二季` | N |
| `Specials`、`Special`、`SP`、`特別篇`、`特别篇` | | 0（特別篇） |

集號從檔名找，依下面的順序，第一個對上的算數：

| 寫法 | 例子 |
| --- | --- |
| `SxxEyy`（也認 `SxxEPyy`，中間可以有空格、點、底線、減號） | `Dark.S01E02.mkv`、`S01 EP02` |
| `NxNN` | `1x02` |
| `第N集`、`第N話`、`第N话`（阿拉伯數字或中文數字） | `第2集`、`第十二集` |
| `Eyy`、`EPyy`（前面是開頭、空格、點、底線、減號或 `[`） | `EP02`、`[E05]` |

有好幾個來源時的優先順序：

- 季：集的 nfo 裡的 `<season>` → 所在的季資料夾 → 檔名裡的 `SxxEyy` → 都沒有就算第 1 季。
- 集號：集的 nfo 裡的 `<episode>` → 檔名。
- 集名：集的 nfo 裡的 `<title>` → 「第 N 集」→ 檔名。

季的名稱是「第 N 季」，第 0 季是「特別篇」。季資料夾裡的 `season.nfo` 可以改季的名稱和簡介。

## 分類資料夾

劇集媒體庫裡可以有分類資料夾，例如 MoviePilot 二級分類的 `电视剧/国产剧/庆余年 (2019)/`。媒體庫路徑直接選 `电视剧` 就好，不用每個分類各加一次。

符合下面任何一項的資料夾是一部劇：

- 裡面有 `tvshow.nfo`。
- 名稱是 `劇名 (年份)`，括號也可以是全形 `（）` 或 `[]`。
- 裡面有季資料夾。
- 裡面直接放著影片或 strm。

其他資料夾當成分類，再往下一層找。媒體庫資料夾底下最多找三層分類資料夾。

注意兩種會認錯的情況：

- 分類資料夾裡直接放了影片，這個分類會被當成一部劇。
- 劇集資料夾沒有年份、沒有 `tvshow.nfo`，影片又都放在不是季資料夾的子資料夾裡（例如 `Disc1`），這部劇會被當成分類。給劇集資料夾加上年份最保險。

想讓每個分類在播放器首頁各佔一列，就每個分類各建一個媒體庫。

## 圖片和 nfo 的檔名

表格裡的 `X` 是影片檔名去掉副檔名。圖片可以是 `.jpg`、`.jpeg`、`.png`、`.webp`。

| 項目 | nfo | 海報 | 背景圖 | 橫幅 | Logo |
| --- | --- | --- | --- | --- | --- |
| 電影 | `X.nfo` | `X-poster`、`X` | `X-fanart`、`X-backdrop` | `X-thumb`、`X-landscape` | `X-logo`、`X-clearlogo` |
| 電影（資料夾裡只有這一部時另外認） | `movie.nfo` | `poster`、`folder`、`cover` | `fanart`、`backdrop`、`background` | `thumb`、`landscape` | `logo`、`clearlogo` |
| 劇集（放在劇集資料夾） | `tvshow.nfo` | `poster`、`folder`、`cover` | `fanart`、`backdrop`、`background` | `thumb`、`landscape` | `logo`、`clearlogo` |
| 季 | 季資料夾裡的 `season.nfo` | 劇集資料夾裡的 `season01-poster`、`season01`（特別篇是 `seasonspecials-poster`、`seasonspecials`）；沒有就用季資料夾裡的 `poster`、`folder`、`cover` | | | |
| 集 | `X.nfo` | `X-thumb`、`X` | | | |

- 集沒有自己的圖時，用劇的橫幅（`thumb`／`landscape`），沒有橫幅就用劇的背景圖。
- 季和集沒有自己的背景圖、橫幅、Logo 時用劇的。
- nfo 讀的欄位：`title`、`originaltitle`、`sorttitle`、`plot`（或 `outline`）、`year`、`premiered`（或 `aired`、`releasedate`）、`rating`、`mpaa`、`genre`、`runtime`（分鐘）、`uniqueid` 和 `tmdbid`／`imdbid`／`tvdbid`、`season`、`episode`，以及演職人員（見下面）。

## 掃描

掃描是把資料夾裡的影片、nfo 和圖片讀進資料庫，播放器看到的就是資料庫裡的內容。不一定要整個重新掃描。

### 在網頁上掃描

「媒體庫」分頁可以：

- 按某個媒體庫右上角的「掃描」，只掃這個媒體庫。
- 按某個資料夾那一行的「掃描」，只掃這個資料夾。資料夾不存在時會標示「資料夾不存在」，這一行沒有「掃描」按鈕。
- 按上方的「掃描資料夾…」，選任何一個媒體庫裡的資料夾，例如一個分類 `电视剧/国产剧` 或一部劇 `电视剧/国产剧/庆余年 (2019)`。選到媒體庫以外的位置會提示「這個位置不在任何媒體庫的資料夾裡」。
- 按「全部重新掃描」，掃全部媒體庫。

掃描時頁面上方會顯示「掃描中」、百分比和正在處理的片名。第一次掃描還不知道總數，顯示來回滑動的忙碌條。同一時間只跑一個掃描，其他的排隊。

### 自動掃描

自動掃描也只掃有變動的地方：

| 時機 | 掃哪裡 |
| --- | --- |
| 每次啟動 Mi302 | 全部媒體庫 |
| 115 同步完成（「同步完自動重新掃描媒體庫」開著時，預設開） | 新增、改名、移動或刪除的檔案所在的劇或電影 |
| MoviePilot 刮削完成 | 刮削過的那些 |
| MoviePilot 或其他工具呼叫 `POST /Library/Media/Updated` | 通知裡的路徑（先依 MoviePilot 的路徑對應換回 Mi302 的路徑）；通知裡沒有路徑時掃全部 |
| 播放器對單一項目按「重新整理」（`POST /Items/{id}/Refresh`，要管理員帳號） | 那部電影或那部劇；對媒體庫按就是整個媒體庫 |
| `POST /Library/Refresh` | 全部媒體庫 |
| 在「媒體庫」分頁按「儲存並掃描」 | 新增或改過的媒體庫；刪掉的媒體庫連同裡面的項目一起移除 |

### 掃描單位

部分掃描以一部劇或一部電影為單位：

- 劇集媒體庫：給一集或一季的路徑，會重掃整部劇；給分類資料夾，會掃裡面所有劇；不在任何劇集資料夾裡的檔案略過。
- 電影媒體庫：重掃變動所在的整個資料夾，因為同一個資料夾裡有幾部影片會影響片名怎麼取；直接放在媒體庫資料夾底下的影片只處理那一部。
- 已經刪掉的路徑：把資料庫裡那底下的項目移除。
- 重複或互相包含的路徑只掃一次。
- 一次超過 300 個單位時（例如第一次全量同步），改成把這些單位所在的媒體庫整個掃一次。

### 觀看紀錄

項目以檔案路徑對應。重新掃描（不論部分或全部）不會改變項目的 id，觀看紀錄、收藏、片頭片尾紀錄都會留著。檔案改名或搬移後是新的項目，舊項目和它的觀看紀錄在下次掃描時移除。

## 網路磁碟還沒掛上

NAS 的 NFS／SMB、Parallels 的 `/media/psf/...` 這類資料夾，開機時可能比 Mi302 晚掛上。媒體庫資料夾不存在、讀不到或完全是空的，Mi302 會當成還沒掛上：

- 整個媒體庫的掃描（包括啟動時那一次）保留這個資料夾原本的項目和觀看紀錄，不會當成影片全被刪了，日誌記一筆警告「媒體庫路徑不存在或是空的」。
- 部分掃描略過這個資料夾。

掛好之後在「媒體庫」分頁按「全部重新掃描」即可。

反過來說，真的把一個資料夾清空時，舊項目會一直留著。這時把這個資料夾從媒體庫移除（或刪掉整個媒體庫），再按「儲存並掃描」。

## 中文片名的排序和搜尋

排序：

- 電影和劇集的排序名用 nfo 的 `<sorttitle>`，沒有就用片名。
- 中文先轉成簡體再轉拼音，一個字一個音節、用空格隔開：`流浪地球2` → `liu lang di qiu 2`。其他文字轉小寫。所以播放器按字母跳轉也有效。
- 集的順序照季、集號，不受影響。

搜尋：

- 片名、原名（nfo 的 `<originaltitle>`）都認。
- 中文片名另外可以用全拼（`qingyunian`）、首字母（`qyn`）、簡體、繁體（`慶餘年`）找到「庆余年」。拼音只從片名產生，不從原名。
- 繁體轉簡體有時用字不同（`慶餘年` 會轉成 `庆馀年`），所以兩個字以上的中文搜尋詞會再用拼音比一次。

排序名和搜尋用的欄位在掃描時產生。每次啟動都會整個掃描一次，所以從舊版更新後，舊資料會自動補齊。

## 演職人員

Mi302 從 nfo 讀演職人員，給播放器顯示：

- `<director>`：導演。
- `<credits>`、`<writer>`：編劇。
- `<actor>`：演員，讀 `name`、`role`、`thumb`、`tmdbid`；`type` 是 `GuestStar` 時算客串。

顯示順序是導演、編劇、演員。點人物可以看他在 Mi302 裡參與的作品，搜尋也找得到人。集和季沒有自己的演職人員時用劇的。

人物照片是 nfo 裡 `<thumb>` 的網址（通常在 TMDB）。播放器要照片時，Mi302 用 302 把它導到那個網址，所以播放器要連得上那台圖片伺服器。

### 中文名

TMDB 的人名常是拼音或英文（Chen He）。「進階設定」分頁的「中文化」卡片裡，「演職人員顯示中文名」（`server.chinese_people`，預設開）開著時，Mi302 在背景查中文名：

- 只查 nfo 裡帶數字 TMDB 人物 id 的人：每部作品的導演、編劇、客串，以及排在前面的演員（程式設定是前 20 位演員，另外留 10 個位置給排在前面的導演和編劇）。
- 先問 MoviePilot 的人物介面（`/api/v1/tmdb/person/{id}`），從 TMDB 的別名裡挑中文的（陈赫）：去掉帶日文假名的，優先本來就是簡體的，都沒有就把繁體轉成簡體。每秒最多問 2 次。
- MoviePilot 沒有的、或還沒設定 MoviePilot、或連不上時，改問 Wikidata（依 TMDB 人物 id，每批 100 位），中文標籤一律轉成簡體。
- 查過沒有的，30 天後再查。有設定 MoviePilot 但這次連不上時，只問了 Wikidata 的人不算查過，下次再問。
- 每 30 分鐘看一次有沒有新的人要查（啟動 1 分鐘後第一次），每次最多 500 位。也可以按「現在查中文名」立刻查。

查到之後播放器顯示中文名，人物資料另外帶上原名（`OriginalTitle`）。用原名、中文名都搜得到人。

「中文化」卡片顯示演職人員、有中文名、還沒查、查過沒有的人數，兩個來源各查到幾位、上次查詢時間和錯誤訊息。還沒設定 MoviePilot 時會提示只能問 Wikidata。

關掉「演職人員顯示中文名」並按「儲存設定」後，播放器馬上改回顯示原名，背景也不再查；已經查到的中文名留在資料庫。

## 類型中文化

- 英文的 TMDB、IMDb 類型照下表換成中文（大小寫不拘），用的是 TMDB 簡體中文的叫法。

- 表裡沒有的英文類型照原樣。換完之後重複的只留一個。

## 媒體庫封面

播放器首頁每個媒體庫的封面，依序用：

1. 上傳的封面。
2. 媒體庫資料夾裡的 `poster`、`folder` 或 `cover` 圖（媒體庫有好幾個資料夾時，用第一個找得到的）。

「媒體庫」分頁每個媒體庫的卡片上看得到封面和它的來源：

- 按「上傳封面」選一張圖，可以是 jpg、png、gif 或 webp，最大 30 MB。
- 有上傳的封面時多一個「改回預設」，按了刪掉上傳的封面，改回資料夾裡的圖。

MoviePilot 的媒體庫封面插件用 Emby 的 `POST /Items/{id}/Images/Primary` 上傳，效果和在網頁上傳一樣，設定方法見 [MoviePilot 整合](MoviePilot-整合)。

上傳的圖片：

- 存在資料資料夾的 `images/`（預設 `data/images/`，一鍵安裝的在 `config/data/images/`）。封面的檔名是 `{項目 id}-primary_image.{副檔名}`。
- 重新掃描不會被蓋掉，也比資料夾裡的圖優先。
- 同一個 API 也能給電影、劇集等其他項目上傳海報、背景圖、橫幅、Logo，規則相同。項目從媒體庫移除時，它上傳的圖片跟著刪掉。
